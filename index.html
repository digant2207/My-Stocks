          📊 How Company Score (Out of 10) is Calculated

          ⭐ 10-Point Normalized Scale: Every stock undergoes comprehensive scoring across 100 raw algorithmic points and is normalized to a clean 10.0 scale (e.g. 85 pts = 8.5 / 10). A score of ≥ 7.0 / 10 signals prime institutional accumulation and swing quality.

          • Net Profit Growth YoY (+10 pts for >15%, +6 pts for >5%).

          🔄 Oversold Rebound Setup & Calculation

          The Oversold Rebound setup filters for high-quality stocks that experienced temporary short-term selling down to critical support zones, offering high-probability mean-reversion swing entries:

          • RSI(14) Cooling (≤ 52 or < 45): Measures sentiment exhaustion where selling pressure has dried up.
          • Volume Dry-Up & Absorption: Daily volume drops below the 20-day average during pullback, followed by bullish price absorption.
          • Support Confluence: Price bouncing off critical key levels (20/50 SMA test, previous swing bottom, or double-bottom neckline).
          • Quality Gate (Score ≥ 6.5 / 10): Ensures you buy valuable fundamental leaders, strictly avoiding speculative falling knives.
          • Swing Targets & SL: Target 1 at 20 DMA / resistance ceiling (1-7D), Target 2 at recent swing high (7-15D), with Stop Loss set 1.5% below the reversal pivot for a 1:2.5+ risk-to-reward ratio.

          🎯 Price Action Logic for Targets & Stop Loss

          1. 52-Week High Breakout Logic

          When price breaks past or trades near 52-Week High:

          • Target 1 (1-7D): 52W High + 1.5× ATR Volatility Expansion.
          • Target 2 (7-15D): 52W High + 3.2× ATR Volatility Expansion.
          • Stop Loss: Placed 1.5% below 20 DMA or 10-day swing bottom.

          2. 20-Day & 50-Day Range Box Breakout Logic

          When price closes above the 20-day or 50-day resistance ceiling:

          • Target 1 (1-7D): Breakout Price + Range Box Height (Measured Move).
          • Target 2 (7-15D): 52-Week High or 1.8x Range Box Height.
          • Stop Loss: Anchored 1% below Previous 20-day Swing Bottom.

          3. 20 DMA Breakout / Rebound Logic

          When price crosses above or bounces from 20-day Moving Average:

          • Target 1 (1-7D): Previous 20-day Swing High (Ceiling).
          • Target 2 (7-15D): 52-Week High level.
          • Stop Loss: Placed 1.5% below 20 DMA level.

          4. Previous Bottom Reversal (Double Bottom W-Pattern)

          When price bounces from support creating a double bottom W-reversal:

          • Target 1 & 2: W-Neckline + Depth of Double Bottom (Measured Move).
          • Stop Loss: Anchored right below the second bottom low pivot.
          Risk-to-Reward Ratio: Ensures every level calculation achieves a disciplined 1 : 2.2+ Risk-to-Reward ratio.

function doPost(e) {
  var data = {};
  try {
    data = JSON.parse(e.postData ? e.postData.contents : "{}");

    data = e.parameter || {};

function handleStockRequest(data) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var rawSym = (data.symbol || "").trim();
    if (!rawSym) {
      return ContentService.createTextOutput(JSON.stringify({status: "error", message: "Symbol empty"}))
        .setMimeType(ContentService.MimeType.JSON);
    }

    var cleanSym = rawSym.replace(/\.(NS|BO)$/i, "").toUpperCase();
    var lastRow = sheet.getLastRow();

    // Check if symbol already exists in Column A
    if (lastRow >= 2) {
      var existingVals = sheet.getRange(2, 1, lastRow - 1, 1).getValues();
      for (var i = 0; i < existingVals.length; i++) {
        var existing = existingVals[i][0].toString().trim().toUpperCase().replace(/\.(NS|BO)$/i, "");
        if (existing === cleanSym) {
          copyFormulasToRow(sheet, i + 2);
          return ContentService.createTextOutput(JSON.stringify({
            status: "warning", 
            message: "Stock " + cleanSym + " is already in the sheet (formulas updated)!"
          })).setMimeType(ContentService.MimeType.JSON);
        }
      }
    }

    var newRow = lastRow + 1;

    // 1. Write clean symbol to Column A
    sheet.getRange(newRow, 1).setValue(cleanSym);

    // 2. Copy formulas & formats from Columns B to L (Columns 2 to 12)
    copyFormulasToRow(sheet, newRow);

    SpreadsheetApp.flush();

    return ContentService.createTextOutput(JSON.stringify({
      status: "success", 
      message: "Added " + cleanSym + " and copied formulas from B to L!"
    })).setMimeType(ContentService.MimeType.JSON);

  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}

// Copies formulas and formatting from previous row to targetRow (Columns B to L)
function copyFormulasToRow(sheet, targetRow) {
  if (targetRow <= 2) return;
  var templateRow = targetRow - 1;
  while (templateRow > 2 && !sheet.getRange(templateRow, 2).getFormula() && !sheet.getRange(templateRow, 3).getFormula()) {
    templateRow--;
  }

  var sourceRange = sheet.getRange(templateRow, 2, 1, 11);
  var targetRange = sheet.getRange(targetRow, 2, 1, 11);
  sourceRange.copyTo(targetRange);

  // Clear manual columns so previous targets aren't duplicated
  var formulas = sourceRange.getFormulas()[0];
  for (var c = 0; c < formulas.length; c++) {
    if (!formulas[c]) {
      targetRange.getCell(1, c + 1).clearContent();
    }
  }
}

// Run this once manually from Apps Script to fill formulas for all existing rows!
function fillFormulasForAllRows() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var lastRow = sheet.getLastRow();
  for (var r = 3; r <= lastRow; r++) {
    copyFormulasToRow(sheet, r);
  }
}
